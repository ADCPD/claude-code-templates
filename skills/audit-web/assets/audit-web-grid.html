Assumptions — Claude Code time

Estimates at "medium" effort, with an agent that has bash access, file/repository reading and web fetch. Excludes tasks requiring a human decision, a meeting, a third-party tool licence (heatmaps, premium backlink tools) or subjective design judgement — human review is still required before the report is shared.

Units

1 man-day = 7 hours. Totals in section 06 are rounded to the nearest quarter hour.
